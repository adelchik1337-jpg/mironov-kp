# Студия мебели Сергея Миронова — живое коммерческое предложение (демо)

Открыть: https://adelchik1337-jpg.github.io/mironov-kp/

- Смета по комнатам: у каждого изделия фото, характеристики и цена, варианты исполнения и доплаты за фурнитуру BLUM — итог пересчитывается сразу.
- Два примера (переключатель над сметой): «Квартира целиком» и «С вариантами и доплатами». Цифры и состав — из реальных смет студии, имена клиентов скрыты.
- Страница — один файл без внешних зависимостей, работает с телефона, печатается в PDF.

Сборка из исходников: `python3 src/build.py` (собирает `src/template.html` + `src/images.json`; результат копируется в `index.html`).
